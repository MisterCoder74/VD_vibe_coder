# 🚀 Vivacity Vibe Coder - Piano di Sviluppo Completo

## 📋 Panoramica Generale

Sistema completo di generazione AI-powered di microapp web con gestione utenti, crediti e deployment automatico.

## 🔧 FASE 1: Sistema Autenticazione

### File: `index.php`

#### Funzionalità
- Form Login/Registrazione in una sola pagina
- Tab switching tra Login e Register
- Validation basic (campi obbligatori)
- Session management

#### Form Registrazione
```html
Username: [input text]
Email:    [input email]
Password: [input password]
[Button: Register]
```

#### Form Login
```html
Username/Email: [input text]
Password:       [input password]
[Button: Login]
```

#### Logica Backend
1. **Register**:
   - Valida campi (non vuoti, email format)
   - Check username/email già esistenti
   - Genera `client_id` univoco (8 char alfanumerici)
   - Crea cartella `./users/{client_id}/`
   - Inizializza `data.json` con `{"api_key": "", "microapps": []}`
   - Salva utente in `users.json`
   - Crediti default: `total_credits: 10000, used_credits: 0`
   - Redirect a `dashboard.php`

2. **Login**:
   - Check username/email in `users.json`
   - Verifica password (plain text match)
   - Crea session con `client_id`
   - Redirect a `dashboard.php`

#### Session Variables
```php
$_SESSION['client_id'] = 'abc123xyz';
$_SESSION['username'] = 'mario';
$_SESSION['email'] = 'mario@example.com';
```

#### Funzioni Helper
```php
function getClientId() {
    session_start();
    return $_SESSION['client_id'] ?? null;
}

function getUserData($clientId) {
    $file = "users/$clientId/data.json";
    return json_decode(file_get_contents($file), true);
}

function updateCredits($clientId, $tokensUsed) {
    // Update used_credits in users.json
    $users = json_decode(file_get_contents('users.json'), true);
    foreach ($users as &$user) {
        if ($user['client_id'] === $clientId) {
            $user['used_credits'] += $tokensUsed;
            break;
        }
    }
    file_put_contents('users.json', json_encode($users, JSON_PRETTY_PRINT));
}
```

## 🔒 FASE 8: Security & Validation

### Implementazioni Base

**1. Session Security**
```php
session_start();
session_regenerate_id(true); // Prevent session fixation
```

**2. Input Sanitization**
```php
function sanitize($input) {
    return htmlspecialchars(trim($input), ENT_QUOTES, 'UTF-8');
}
```

**3. File Path Validation**
```php
function isValidPath($clientId, $path) {
    $realBase = realpath("users/$clientId");
    $realPath = realpath($path);
    return strpos($realPath, $realBase) === 0;
}
```

**4. Credits Validation**
```php
function hasCredits($clientId) {
    $user = getUserFromJson($clientId);
    return ($user['total_credits'] - $user['used_credits']) > 0;
}
```

**5. Email Validation**
